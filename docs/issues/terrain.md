Das Terrain einer Map ist außen von Gebirgen begrenzt. Innerhalb der Karte gibt es (meistens?) zwei größere blockierende Felsformationen, die den Charkter der Map maßgeblich bestimmen.

Für die Desert-Karte passt das. Für Alien Planet und Mothership sollten das keine Felsformationen sein sondern andere Models.

Alien Planet: Große, dichte Alienfauna
Mothership: Große Hangar
