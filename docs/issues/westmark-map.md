- [ ] **Vor weiterer öffentlicher Weitergabe Herkunft/Nutzungsfreigabe der eingebetteten Bildquelle klären und nachvollziehbar dokumentieren.** Statischer Abgleich auf `937914e`: `assets/textures/texture-westmark-spruce.webp` wird durch [den Texturgenerator](../../scripts/embed-textures.mjs) weiterhin in `assets.js` eingebettet und damit ausgeliefert, unabhängig von aktueller GPU-Residenz. Opake Materialien sind prozedural. Fehlender Herkunftsnachweis im Repository ist kein Nachweis fehlender Rechte; Klärung durch den Rechteinhaber erforderlich. Keine ungefragte Quellenlöschung.
